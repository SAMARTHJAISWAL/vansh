A real parser, in your browser

    
vansh is written in OCaml. Its hand-written SQL parser and scope resolver are compiled to JavaScript with
      js_of_ocaml, so this page runs exactly the same analysis as the command-line tool. Your SQL never leaves the tab.

  

  

    
Through everything that moves a value

    
CTEs, subqueries, joins, UNION, SELECT * and EXCLUDE, window functions,
      CASE, lateral aliases, UNNEST/FLATTEN, and dbt's ref(),
      source(), if blocks and common macros.
